🚀 FLUJO DE LA APLICACIÓN
═════════════════════════════════════════════════════════════════════════════

1. INICIO (SplashActivity)
   ↓
   ├→ ¿Hay token guardado?
   │   YES → CatalogActivity
   │   NO → LoginActivity
   
2. LOGIN (LoginActivity)
   ↓
   ├→ Validar email y contraseña
   ├→ POST /api/auth/login
   ├→ Guardar token en EncryptedSharedPreferences
   └→ CatalogActivity

3. CATÁLOGO (CatalogActivity)
   ↓
   ├→ GET /api/video/list (autenticado)
   ├→ Mostrar lista de cursos
   └→ Seleccionar video → PlayerActivity

4. REPRODUCTOR (PlayerActivity)
   ↓
   ├→ GET /api/video/{videoId}/play
   ├→ Aplicar FLAG_SECURE (anti-screenshot)
   ├→ Cargar HLS con DRM
   ├→ Reproducir con ExoPlayer
   ├→ Mostrar marca de agua forense
   └→ Monitorear sesión (heartbeat)

🔧 CÓMO USAR EN ANDROID STUDIO
═════════════════════════════════════════════════════════════════════════════

OPCIÓN 1: Importación Rápida
  1. File → Open
  2. Navegar a: player-apk-android
  3. Click "Open"
  4. Esperar sincronización de Gradle
  5. Shift+F10 para compilar y ejecutar

OPCIÓN 2: Setup con Scripts
  Windows:  setup-windows.bat
  Linux:    ./setup-linux-mac.sh

OPCIÓN 3: Línea de Comandos
  cd player-apk-android
  ./gradlew assembleDebug      # APK Debug
  ./gradlew assembleRelease    # APK Release (requiere keystore)
