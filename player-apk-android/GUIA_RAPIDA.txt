═════════════════════════════════════════════════════════════════════════════
PASO 1: IMPORTAR PROYECTO
═════════════════════════════════════════════════════════════════════════════

1. Abre Android Studio

2. En el menú principal:
   File → Open
   
3. Navega a:
   d:\descargas\proyectos hunter 2\reproductor-cursos-master\player-apk-android
   
4. Haz clic en "Open"
   
5. ESPERA: Android Studio sincronizará Gradle (puede tomar 2-5 minutos)
   
6. Verás en la esquina inferior: "Gradle build finished"

═════════════════════════════════════════════════════════════════════════════
PASO 2: CONFIGURAR DISPOSITIVO
═════════════════════════════════════════════════════════════════════════════

OPCIÓN A: Dispositivo Físico
────────────────────────────
1. Conecta tu teléfono Android vía USB
2. En el teléfono: Settings → About → tap "Build Number" 7 veces
3. Settings → Developer Options → USB Debugging → ON
4. Android Studio detectará automáticamente el dispositivo

OPCIÓN B: Emulador
──────────────────
1. En Android Studio: Tools → Device Manager
2. Create device → selecciona "Pixel 5" (o similar)
3. Finish
4. Espera a que se inicie el emulador

═════════════════════════════════════════════════════════════════════════════
PASO 3: COMPILAR Y EJECUTAR
═════════════════════════════════════════════════════════════════════════════

1. En Android Studio, en el menú principal:
   Build → Build Bundle(s) / APK(s) → Build APK(s)
   
2. O simplemente presiona: Shift + F10
   
3. Se abrirá ventana de selección de dispositivo
   Selecciona tu dispositivo y haz clic "OK"
   
4. ESPERA: La compilación tarda 30-60 segundos la primera vez
   
5. ¡LISTO! La app debería instalarse y ejecutarse en el dispositivo

GENERACIÓN DE APK PARA DISTRIBUCIÓN
═════════════════════════════════════════════════════════════════════════════

APK Debug (para testing):
 Build → Build Bundle(s) / APK(s) → Build APK(s)

APK Release (producción con firma):
 Build → Build Bundle(s) / APK(s) → Build APK(s)
 Selecciona Release
 Archivo: app/build/outputs/apk/release/app-release.apk
 
Bundle para Google Play:
 Build → Build Bundle(s) / APK(s) → Build Bundle(s)
 Archivo: app/build/outputs/bundle/release/app-release.aab

═════════════════════════════════════════════════════════════════════════════
CAMBIAR URL DEL SERVIDOR
═════════════════════════════════════════════════════════════════════════════

Si necesitas cambiar la URL del servidor:

1. Abre archivo: app.properties
2. Cambia la línea:
   API_BASE_URL=http://localhost:3000/
   
   Por tu servidor:
   API_BASE_URL=https://tu-dominio.com/
   
3. Recompila: Shift + F10

SOLUCIÓN DE PROBLEMAS
═════════════════════════════════════════════════════════════════════════════

❌ "Gradle sync failed"
   → Build → Clean Project
   → Build → Rebuild Project
   → Si persiste: File → Invalidate Caches → OK

❌ "No devices detected"
   → Verifica: adb devices
   → Intenta: adb kill-server && adb start-server
   → Recarga driver USB en dispositivo

❌ "Installation failed"
   → Desinstala primero: adb uninstall com.edulock.player
   → Reintenta compilar

❌ "Video no se reproduce"
   → Verifica que el servidor Node.js está corriendo
   → Verifica la URL en app.properties
   → Revisa logs: adb logcat | grep EDULOCK
