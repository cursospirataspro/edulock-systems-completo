🎯 RESPUESTAS A TUS PREGUNTAS ESPECÍFICAS

P1: ¿Cómo está conectado APK a Render?
───────────────────────────────────────
Mediante HTTPS/REST API:
• APK → POST/GET a Render
• Render responde con JSON
• Totalmente automático

URL Base: http://localhost:3000/ (o tu dominio en Render)
Endpoints: /api/auth/*, /api/video/*, /api/watermark/*


P2: ¿Cómo le llega el acceso al usuario?
────────────────────────────────────────
NO es notificación instantánea.
Es DETECCIÓN AUTOMÁTICA cada 10 segundos:

1. Él espera viendo "⏳ Pendiente"
2. Cada 10s la APK pregunta "¿ya me aprobaron?"
3. Render responde "Aún no" o "¡Sí!"
4. APK automáticamente actualiza pantalla

Tiempo total: 0-10 segundos después de que apruebas


P3: ¿Cómo funciona exactamente?
──────────────────────────────
Así de simple:

User:  EMAIL, click REGISTRAR
  │
  └─► APK: Envía datos a Render
       └─► Render: Guarda en BD (status="pending")
           └─► APK: Muestra "⏳ Pendiente"

⏰ ADMIN APRUEBA:

Admin: [✓ APROBAR en Dashboard]
  │
  └─► Render: Actualiza BD (status="approved")

📲 USER RECIBE (AUTO):

APK: GET /check-device (cada 10s)
  │
  └─► Render: "✅ Aprobado"
       └─► APK: "¡Acceso concedido!"
           └─► User: Ve sus cursos
               └─► [▶ REPRODUCIR]

📊 COMPARACIÓN: ¿CÓMO LLEGABA ANTES (SIN APK)?
═════════════════════════════════════════════════════════════════════════════

ANTES (Reproductor Windows):
   Usuario → Abre reproductor → Login directo
   Admin → Crea usuario manualmente en BD
   Usuario → Inicia sesión y accede

AHORA (Con APK):
   Usuario → Instala APK → Solicita acceso automáticamente
   Admin → Revisa solicitud en dashboard → Aprueba
   Usuario → APK detecta automáticamente → Acceso sin hacer nada

VENTAJA:
   ✓ No necesitas crear usuarios manualmente
   ✓ No necesitas compartir credenciales
   ✓ Usuario controla cuándo solicita
   ✓ Admin controla quiénes aprueban
   ✓ Rastreo completo de quién aprobó cuándo

   ✓ HTTPS (canal encriptado)

   ✓ Datos en BD encriptados

   ✓ FLAG_SECURE: No screenshot, no grabación
   ✓ DRM Widevine: Cifrado de contenido
   ✓ Watermark forense: Si se filtra, sabes quién
   ✓ Límite de dispositivos: Max 2 por usuario
