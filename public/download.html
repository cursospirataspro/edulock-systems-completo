Instrucciones de instalación en Windows

Para ver los videos protegidos desde tu computadora, debes instalar el reproductor oficial para Windows.

Requisitos

  • Windows 10 o Windows 11 (64 bits).
  • Conexión estable a internet.
  • Espacio disponible para la instalación.
  • Usar el correo autorizado con el que compraste o te registraste.
  • Descargar el reproductor únicamente desde el enlace oficial.

Pasos de instalación

  1. Presiona el botón de descarga para Windows.
  2. Espera a que termine la descarga del instalador.
  3. Abre el archivo descargado.
  4. Si Windows solicita permisos, presiona Sí.
  5. Sigue los pasos del asistente de instalación.
  6. Espera a que finalice el proceso.
  7. Una vez instalado, abre Edulock Systems Player desde el escritorio o desde el menú Inicio.
  8. Inicia sesión con tu correo autorizado.
  9. Una vez validado tu acceso, podrás reproducir tus clases desde el reproductor.

Si Windows muestra una advertencia de seguridad

En algunos equipos Windows puede mostrar una advertencia al ejecutar una aplicación descargada de internet. Si aparece una ventana indicando que Windows protegió tu equipo:

  1. Presiona Más información.
  2. Selecciona Ejecutar de todas formas.
  3. Continúa con la instalación normalmente.

Este aviso puede aparecer en algunos equipos y no significa que exista un problema con el reproductor.

Si el navegador bloquea la descarga

Algunos navegadores pueden mostrar advertencias al descargar archivos ejecutables. Si ocurre:

  1. Verifica que estés descargando desde el enlace oficial.
  2. Busca la opción Conservar archivo, Mantener o Descargar de todos modos.
  3. Espera a que finalice la descarga.
  4. Ejecuta el instalador normalmente.

Si el antivirus muestra una advertencia

Algunos antivirus pueden solicitar una confirmación adicional porque el reproductor fue descargado desde internet. Si aparece una advertencia:

  1. Verifica que descargaste el archivo desde el sitio oficial.
  2. Permite la ejecución o instalación si tu antivirus solicita confirmación.
  3. Continúa con la instalación.

Si no estás seguro de cómo hacerlo, comunícate con soporte.

Si la aplicación no abre correctamente

Si el reproductor se instaló pero no abre:

  1. Reinicia la computadora.
  2. Verifica tu conexión a internet.
  3. Intenta ejecutar nuevamente la aplicación.
  4. Asegúrate de tener Windows 10 o Windows 11 actualizado.
  5. Si el problema continúa, comunícate con soporte indicando el mensaje de error que aparece.

Importante

  • No compartas tu cuenta.
  • Usa únicamente el correo autorizado.
  • El acceso está vinculado a tus dispositivos autorizados.
  • Si cambias de computadora o tienes problemas para ingresar, comunícate con soporte.
  • El reproductor está diseñado para proteger el contenido del curso.

Lo que no está permitido

  • No se permite descargar los videos.
  • No se permite grabar la pantalla.
  • No se permite tomar capturas del contenido.
  • No se permite utilizar herramientas externas para copiar o extraer el video.

Si el sistema detecta un uso no permitido, el reproductor puede pausar, cerrar la sesión o bloquear la reproducción.

Instrucciones de instalación en Android

Para ver los videos protegidos desde tu celular Android, debes instalar el reproductor oficial.

Requisitos

  • Tener un celular Android compatible.
  • Contar con conexión a internet estable.
  • Tener espacio disponible en el dispositivo.
  • Usar el correo autorizado con el que compraste o te registraste.
  • Descargar el aplicativo únicamente desde el enlace oficial que te proporcionamos.

Pasos de instalación

  1. Presiona el botón de descarga del reproductor para Android.
  2. Espera a que termine la descarga del archivo.
  3. Cuando finalice, abre el archivo descargado desde tu navegador o desde la carpeta Descargas.
  4. Si Android muestra un aviso de seguridad, presiona Configuración o Ajustes.
  5. Activa la opción Permitir instalar aplicaciones de esta fuente.
  6. Regresa al archivo descargado.
  7. Presiona Instalar.
  8. Espera a que la instalación termine.
  9. Cuando aparezca la opción, presiona Abrir.
  10. Inicia sesión con tu correo autorizado.
  11. Una vez validado tu acceso, podrás reproducir tus clases desde el reproductor.

Si Android bloquea la instalación

En algunos celulares Android puede aparecer un aviso porque la aplicación no fue instalada desde Google Play. Si aparece ese aviso, realiza lo siguiente:

  1. Presiona Configuración, Ajustes o Permitir desde esta fuente.
  2. Busca la opción Instalar aplicaciones desconocidas.
  3. Selecciona el navegador o la app desde donde descargaste el archivo, por ejemplo Chrome, Files o Administrador de archivos.
  4. Activa Permitir desde esta fuente.
  5. Vuelve al archivo descargado.
  6. Presiona nuevamente Instalar.

Este aviso es normal cuando se instala una aplicación externa. Solo debes instalar el reproductor desde el enlace oficial que te entregamos.

Si Android muestra “archivo puede ser dañino”

Si el navegador muestra un aviso indicando que el archivo puede ser dañino:

  1. Verifica que estés descargando desde el enlace oficial.
  2. Presiona Descargar de todos modos o Conservar archivo, si aparece esa opción.
  3. Cuando termine la descarga, abre el archivo.
  4. Continúa con la instalación.

Si Play Protect muestra una advertencia

En algunos dispositivos puede aparecer una advertencia de Play Protect porque la app no proviene de Google Play. Si aparece esa advertencia:

  1. Verifica que descargaste el reproductor desde el enlace oficial.
  2. Presiona Más detalles si aparece esa opción.
  3. Selecciona Instalar de todos modos o Abrir de todos modos, si el dispositivo lo permite.
  4. Si el celular no permite continuar, comunícate con soporte para recibir ayuda.

Si la app no abre después de instalar

Si el reproductor se instala, pero no abre correctamente:

  1. Verifica tu conexión a internet.
  2. Cierra la aplicación y vuelve a abrirla.
  3. Reinicia tu celular.
  4. Confirma que tu Android sea compatible.
  5. Si el problema continúa, comunícate con soporte indicando el modelo de tu celular y una captura del mensaje que aparece.

Instrucciones de instalación en Linux

Para ver los videos protegidos desde tu computadora con Linux, debes instalar o ejecutar el reproductor oficial.

Requisitos

  • Usar una distribución compatible, como Ubuntu, Debian o similares.
  • Tener conexión estable a internet.
  • Tener espacio disponible en el dispositivo.
  • Usar el correo autorizado con el que compraste o te registraste.
  • Descargar el reproductor únicamente desde el enlace oficial.

Pasos de instalación

  1. Presiona el botón de descarga para Linux.
  2. Espera a que termine la descarga del archivo.
  3. Busca el archivo descargado en la carpeta Descargas.
  4. Haz clic derecho sobre el archivo.
  5. Entra en Propiedades.
  6. Busca la sección de Permisos.
  7. Activa la opción Permitir ejecutar el archivo como un programa.
  8. Cierra la ventana de propiedades.
  9. Haz doble clic sobre el archivo para abrir el reproductor.
  10. Inicia sesión con tu correo autorizado.
  11. Una vez validado tu acceso, podrás reproducir tus clases desde el reproductor.

Si Linux no permite abrir el archivo

En algunas distribuciones Linux, el sistema puede bloquear la ejecución del archivo descargado por seguridad. Si ocurre esto:

  1. Haz clic derecho sobre el archivo descargado.
  2. Selecciona Propiedades.
  3. Entra en Permisos.
  4. Activa Permitir ejecutar el archivo como un programa.
  5. Guarda los cambios.
  6. Intenta abrir nuevamente el reproductor.

Este aviso es normal cuando se descarga una aplicación desde internet.

Si aparece un aviso de seguridad

Si Linux muestra un aviso indicando que el archivo proviene de una fuente externa:

  1. Verifica que descargaste el reproductor desde el enlace oficial.
  2. Confirma que deseas abrir o ejecutar el archivo.
  3. Continúa con la instalación o apertura del reproductor.

Si el reproductor no abre correctamente

Si el reproductor no abre después de seguir los pasos:

  1. Verifica tu conexión a internet.
  2. Cierra cualquier ventana abierta del reproductor.
  3. Reinicia tu computadora.
  4. Intenta abrir nuevamente el archivo.
  5. Confirma que estás usando una distribución compatible.
  6. Si el problema continúa, comunícate con soporte indicando tu distribución de Linux y el mensaje que aparece.

El reproductor para iPhone estará disponible próximamente. Cuando se habilite, podrás instalarlo desde el enlace oficial que te proporcionaremos.

Requisitos

  • Tener un iPhone compatible.
  • Contar con conexión estable a internet.
  • Tener espacio disponible en el dispositivo.
  • Usar el correo autorizado con el que compraste o te registraste.
  • Instalar el reproductor únicamente desde el enlace oficial.

Importante antes de instalar

En iPhone no se instala igual que en Android, Windows o Mac. No debes intentar instalar archivos de Android, Windows, macOS o Linux en iPhone, ya que no son compatibles.

Cuando la versión para iPhone esté disponible, se entregará mediante uno de estos métodos:

  • App Store.
  • TestFlight.
  • Enlace oficial autorizado.

Pasos de instalación cuando esté disponible

  1. Presiona el botón oficial de instalación para iPhone.
  2. Abre el enlace desde tu iPhone.
  3. Si el enlace te lleva a App Store, presiona Obtener o Instalar.
  4. Si el enlace te lleva a TestFlight, instala primero la app TestFlight desde App Store.
  5. Abre la invitación oficial del reproductor en TestFlight.
  6. Presiona Instalar.
  7. Espera a que termine la instalación.
  8. Abre el reproductor desde la pantalla principal de tu iPhone.
  9. Inicia sesión con tu correo autorizado.
  10. Una vez validado tu acceso, podrás reproducir tus clases desde el reproductor.

Si iPhone no permite instalar la app

Si el iPhone no permite instalar el reproductor, revisa lo siguiente:

  1. Verifica que estás usando el enlace oficial.
  2. Confirma que tienes conexión a internet.
  3. Asegúrate de tener espacio disponible.
  4. Revisa que tu iPhone tenga una versión de iOS compatible.
  5. Si estás usando TestFlight, confirma que la invitación siga activa.
  6. Si el problema continúa, comunícate con soporte.

Si el enlace de TestFlight no funciona

Si el enlace de TestFlight aparece como vencido, lleno o no disponible:

  1. Verifica que abriste el enlace desde tu iPhone.
  2. Confirma que tienes instalada la app TestFlight.
  3. Intenta abrir nuevamente la invitación oficial.
