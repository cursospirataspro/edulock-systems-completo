RESUMEN EJECUTIVO:
─────────────────

Los usuarios reciben NOTIFICACIONES PUSH en tiempo real cuando su solicitud 
de acceso es APROBADA por el administrador.

La APK captura TODA la información del dispositivo (igual que el reproductor PC):
  • Modelo del dispositivo (ej: "Samsung Galaxy A10")
  • Serial del dispositivo (ej: "R38M7087CKL")
  • ID único persistente (SHA-256 basado en hardware)
  • Versión de Android
  • RAM disponible
  • CPU cores
  • Build fingerprint

Todo esto se envía al backend cuando el usuario se registra.

  }

[Backend procesa]
  1. Actualiza BD:
     UPDATE registration_requests 
     SET status = 'approved' WHERE id = 'req_123456789'
  
  2. Obtiene FCM token de la solicitud:
     fcmToken = "eNgc0O9d_qE:APA91bGm7x..."
  
  3. ✅ ENVÍA NOTIFICACIÓN PUSH:
     ┌──────────────────────────────────────────┐
     │ Firebase Admin SDK                       │
     │ sendApprovalNotification(                │
     │   fcmToken,                              │
     │   "usuario@ejemplo.com",                 │
     │   ["course_python", "course_react"]      │
     │ )                                        │
     └──────────────────────────────────────────┘

[Firebase Cloud Messaging]
  └─ Encamina el mensaje por Internet
  └─ Lo envía al APK registrado con ese token

🔄 ALTERNATIVAS A NOTIFICACIONES PUSH
═══════════════════════════════════════════════════════════════════════════

Si por alguna razón FCM no funciona, los usuarios IGUAL recibirán acceso:

OPCIÓN 1: Polling cada 10 segundos (IMPLEMENTADO ACTUALMENTE)
────────────────────────────────────────────────────────────
  • APK consulta GET /api/auth/check-device cada 10s
  • Máximo espera: 10 segundos
  • Funciona incluso sin permisos de notificación
  • No requiere Firebase

OPCIÓN 2: WebSockets en tiempo real (FUTURO)
────────────────────────────────────────────
  • Conexión bidireccional
  • Notificación < 1 segundo
  • Más complejo de implementar

OPCIÓN 3: Email automático (OPCIONAL)
───────────────────────────────────────
  • Backend envía email cuando se aprueba
  • Usuario no ve notificación en app
  • Pero puede revisar email
